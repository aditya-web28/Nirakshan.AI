# NIRAKSHAN AI — Demo Guide

## Live Demo

**Live Application:**  
https://nirakshan-ai.onrender.com/

## Demo Flow

The recommended demonstration flow is:

1. Open the NIRAKSHAN AI dashboard.
2. Review the overall project monitoring summary.
3. Open the Projects section.
4. Select a project to view its detailed information.
5. Review the project's cost, expenditure, progress and risk indicators.
6. Open Risk & Early Warnings.
7. Review high-risk projects and warning indicators.
8. Open Analytics to explore project-level trends and risk distribution.
9. Open the NIRAKSHAN AI Assistant.
10. Ask questions about project risks, delays and risk drivers.

## Main Modules

### Dashboard

Provides an overview of monitored projects and their current indicators.

### Projects

Provides project-level information and allows users to inspect individual projects.

### Project Details

Shows detailed project information including cost, expenditure, progress and risk indicators.

### Risk & Early Warnings

Highlights projects requiring attention and presents risk-related information.

### Analytics

Provides visual analysis of project performance and risk patterns.

### NIRAKSHAN AI Assistant

Provides an AI-assisted interface for project intelligence queries.

## Prototype Data

The current application uses sample/demo data to demonstrate the interface and workflow.

The prototype does not claim to use live government project data.
